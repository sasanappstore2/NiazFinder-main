# تشخیص خودکار شهر (Geolocation)

## رفتار

| حالت | نتیجه |
|------|--------|
| اولین بازدید، بدون شهر در URL/کوکی | درخواست GPS → نزدیک‌ترین شهر → انتقال به `/s/{slug}` |
| رد GPS | «تمام ایران» بدون تغییر |
| شهر در URL یا کوکی | بدون override |
| دکمه «موقعیت من» در دیالوگ | تشخیص مجدد |

مختصات خام ذخیره **نمی‌شود**؛ فقط `lastDetectedSlug` در کوکی `needfinder_prefs`.

## توسعه

```bash
# تست: پاک کردن کوکی needfinder_prefs → باز کردن /
# اجازه موقعیت → redirect به /s/tehran (یا نزدیک‌ترین شهر)
```

## چک‌لیست QA
