# Performance

## هدف
ملاحظات کارایی که در کار جلسات قبلی کشف شدند — تجمیع‌شده تا تکرار نشوند.

## یافته‌های شناخته‌شده
- **Lighthouse performance/accessibility**: در فاز PWA این پروژه بررسی و اصلاح شد (نگاه کنید به کامیت‌های `feat: PWA completion` در تاریخ ریپو).
- **Intake سرعت**: بهبودهای واقعی = navigation غیربلاک‌کننده + گرم‌کردن ایندکس از قبل؛ چیزهایی که امتحان شد ولی revert شد هم مستند است — به [[../Architecture/Backend/need-intake-engine|Architecture/Backend/need-intake-engine]] مراجعه کنید (جزئیات در حافظهٔ ایجنت، نیاز به نگارش کامل در فاز‌های آینده).
- **چت**: محدودیت ۳۰ پیام برای کارایی رندر.
- **Turbopack cache trap**: به [[../Debug/README|Debug/]] مراجعه کنید — نه صرفاً کارایی، بلکه صحت build.
