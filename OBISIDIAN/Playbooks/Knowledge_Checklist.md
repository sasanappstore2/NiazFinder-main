# چک‌لیست دانش (Knowledge)

برای بازبینی دوره‌ای سلامت Vault (پیشنهاد: هر چند ماه یک‌بار):

- [ ] آیا لینک شکسته‌ای پیدا شد؟ (`grep -r "\[\[" OBISIDIAN` و بررسی نمونه‌ای)
- [ ] آیا فایل orphan جدیدی (بدون لینک ورودی) ایجاد شده؟
- [ ] آیا تگ‌های جدید خارج از [[../Indexes/Tag_Taxonomy|Indexes/Tag_Taxonomy]] استفاده شده‌اند؟
- [ ] آیا محتوای `10_Product_Areas/` یا `Architecture/` از کد واقعی عقب افتاده (stale)؟
- [ ] آیا ADR/RFC جدیدی باید نوشته شود برای تصمیم‌های بزرگ اخیر؟
- [ ] آیا `AI/Agent_Memory.md` بیش‌ازحد بزرگ شده و نیاز به تلخیص/انتقال ورودی‌های قدیمی به Decision Logs دارد؟
