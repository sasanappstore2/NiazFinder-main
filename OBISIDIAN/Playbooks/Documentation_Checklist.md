# چک‌لیست مستندسازی

قبل از merge کردن PR که یک ماژول/فیچر جدید اضافه می‌کند:

- [ ] آیا یک سند در `Architecture/` برای این دامنه هست یا باید ساخته/به‌روز شود؟
- [ ] آیا لینک‌های جدید همه به مسیر فایل واقعی اشاره می‌کنند (نه کد کپی‌شده)؟
- [ ] آیا محتوای `docs/` تکرار شده یا فقط لینک خورده؟
- [ ] آیا فرضیات (نه واقعیت‌های استخراج‌شده از کد) صراحتاً برچسب خورده‌اند؟
- [ ] آیا این تغییر یک قانون/محدودیت جدید کشف کرد که باید به [[../AI/Engineering_Constitution|AI/Engineering_Constitution]] اضافه شود؟
- [ ] آیا تصمیم بزرگ معماری بود که نیاز به ADR دارد، یا تصمیم کوچک که Decision Log کافی است؟
- [ ] frontmatter (`title`, `tags`, `status`) طبق قرارداد موجود پر شده؟
