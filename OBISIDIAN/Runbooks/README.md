# Runbooks

## هدف
رویه‌های عملیاتی گام‌به‌گام برای اجرا/راه‌اندازی سیستم — نه بازبینی کیفیت (آن Playbooks است).

## اسناد
- راه‌اندازی محلی (لایهٔ قدیمی، دست‌نخورده، هنوز معتبر): [[../90_Technical_Appendix/Index/LocalRunbook|90_Technical_Appendix/Index/LocalRunbook]]
- متغیرهای محیطی: [[../90_Technical_Appendix/Index/EnvMap|90_Technical_Appendix/Index/EnvMap]]

## روابط
- دستورهای اجرا هم در ریشهٔ ریپو مستند شده‌اند: `CLAUDE.md` (بخش «Run»).
- برای دیباگ وقتی چیزی خراب است: [[../Debug/README|Debug/]]

## ترتیب خواندن
`LocalRunbook` برای راه‌اندازی اولیه → `EnvMap` برای هر متغیر محیطی خاص.
