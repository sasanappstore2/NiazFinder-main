# واژه‌نامهٔ پروژه (فارسی ↔ انگلیسی)

| فارسی | انگلیسی | توضیح |
|-------|---------|-------|
| نیاز | Need / ServiceRequest | آگهی که کاربر ثبت می‌کند |
| لید | Lead / NeedLeadOutreach | معرفی یک نیاز به یک کسب‌وکار |
| لید باکیفیت | Quality Lead | لید با شماره تاییدشده + بودجه + منطقه + urgency مشخص |
| لید عادی | Standard Lead | لید بدون همهٔ ۴ شرط بالا |
| کسب‌وکار | Business (BusinessProfile) | مشاور/شرکت که به لید دسترسی می‌خرد |
| کیف پول | Wallet | موجودی داخلی هر کاربر برای پرداخت |
| اعتبار هدیه | Bonus Credit | اعتبار رایگان (signup bonus، رفرال) |
| رفرال | Referral | سیستم دعوت کاربر جدید با پاداش دوطرفه |
| اشتراک | Subscription | پلن Free/Pro/Business با تخفیف روی فی لید |
| ثبت نیاز | Need Intake | فرایند `/post` — تبدیل متن آزاد به آگهی ساختاریافته |
| بازار | Marketplace | صفحات مرور `/n` (نیاز)، `/b` (کسب‌وکار) |
| موتور تطبیق | Smart Matching | تطبیق نیاز↔کسب‌وکار + ارسال لید |
| دستیار نیازفایندر | Platform AI Agent | چت‌بات مکالمه‌ای پلتفرم (نه موتور intake) |
| صف moderation | Moderation Queue | بازبینی آگهی قبل از انتشار عمومی |
| منطقه | Neighborhood | واحد جغرافیایی زیر شهر برای فیلتر |
| دیل تایپ | Deal Type | نوع معامله (خرید/رهن/اجاره/...) |
