# Agent Memory

یادداشت‌های زندهٔ ایجنت‌های AI — این فایل به‌مرور توسط ایجنت‌هایی که روی این پروژه کار می‌کنند به‌روزرسانی می‌شود. برخلاف ADR (رسمی) یا Decision Log (تصمیم)، این‌جا مشاهدات عملیاتی/رفتاری ثبت می‌شود.

## مشاهدات ثبت‌شده

### ۲۰۲۶-۰۷-۱۶ — بازسازی کامل OBISIDIAN
این جلسه کل ساختار «Engineering Brain» فعلی را ساخت. اگر به این فایل برخوردید و ساختار جدید به نظرتان ناقص/نادرست می‌رسد، به‌جای بازنویسی از صفر، [[../Indexes/Migration_Summary|Indexes/Migration_Summary]] را بخوانید تا بدانید چه چیزی عمداً حذف/تغییر شکل داده شده.

### الگوی رفتاری Browser-pane
کلیک/تایپ خودکار در Browser pane این محیط گاهی به‌طور نامعتبر شکست می‌خورد (متن ثبت نمی‌شود، navigation برنمی‌گردد) — این یک باگ کد نیست؛ اگر با آن مواجه شدید، `fetch` مستقیم از کنسول را جایگزین کنید.

### همیشه دو ممیزی موازی قبل از کار بزرگ
برای کارهای بزرگ چندفایلی (مثل این بازسازی)، اجرای ۲ Explore agent موازی (یکی روی محتوای موجود، یکی روی معماری هدف) قبل از نوشتن پلن، هزینهٔ اشتباه بزرگ را کم می‌کند.
