# CLAUDE_CONTEXT

سند master برای هر ایجنت AI (Claude، Cursor، یا هر ابزار دیگر) که برای اولین بار وارد این ریپو می‌شود. اگر فقط یک فایل از کل Vault را می‌خوانید، همین باشد.

## چشم‌انداز پروژه
نیازفایندر (نیاز فایندر) یک **Marketplace معکوس** فارسی‌زبان است: کاربر نیاز خود را با متن آزاد ثبت می‌کند («آپارتمان ۹۰ متری در قاسم‌آباد مشهد می‌خواهم»)؛ موتور intake آن را به فیلدهای ساختاریافته تبدیل می‌کند؛ پلتفرم نیاز را به کسب‌وکارهای مرتبط (فاز اول: مشاوران املاک) می‌رساند؛ کسب‌وکار برای دسترسی به لید هزینه می‌پردازد.

## معماری خلاصه
Next.js 16 + React 19 روی Bun؛ frontend و backend هر دو در همان اپ Next.js (`src/app/api/**`، ۲۱۶ روت)؛ Postgres+pgvector از طریق Prisma 6؛ `src/intake/` موتور اصلی تحلیل نیاز (rules-first، LLM اختیاری)؛ `mini-services/` برای worker/chat/AI sidecar. نقشهٔ کامل: [[../Architecture/README|Architecture/]].

## اهداف کسب‌وکاری
مدل درآمدی: Pay-as-you-go + Wallet — کاربر عادی هرگز پول نمی‌دهد؛ کسب‌وکار برای دسترسی به لید واقعی هزینه می‌کند. جزئیات: [[../Business Logic/README|Business Logic/]]، [[../ADR/011-wallet-monetization-strategy|ADR-011]].

## سیستم‌های فعلی (مهم — سردرگمی رایج)
پروژه **چند سیستم AI مجزا** دارد که نباید با هم قاطی شوند:
1. `src/intake/` — موتور تحلیل نیاز در `/post`
2. `src/lib/ai-agent/` — دستیار چت پلتفرم («دستیار نیازفایندر»)
3. `src/ai/` — لایهٔ انتزاع چندارائه‌دهنده
4. `src/lib/rag/` — grounding مبتنی بر بازیابی

جزئیات و هشدار کامل: [[../Architecture/AI/README|Architecture/AI/]].

## محدودیت‌های حیاتی (نقض‌نشدنی)
1. **کاربر عادی هیچ‌وقت برای ثبت نیاز پول پرداخت نمی‌کند.**
2. **هرگز به `/post` (موتور intake) آسیب نزنید** مگر صراحتاً همان کار درخواستی باشد — این تجربهٔ کاربری هستهٔ پلتفرم است.
3. **همهٔ پرداخت‌ها از طریق Wallet انجام می‌شود** — حتی درگاه فقط برای شارژ است.
4. **الگوی idempotent lock-check** برای هر عملیات پولی جدید تکرار شود (مرجع: `src/lib/smart-matching/wallet-lead-fee.ts`).
5. **`prisma db push` را با احتیاط اجرا کنید** — می‌تواند drift های نامرتبط قدیمی را بی‌صدا اعمال و داده واقعی را drop کند (حادثهٔ واقعی ۲۰۲۶-۰۷-۱۶، به [[../Debug/README|Debug/]] مراجعه کنید).

## پوشه‌ها/فایل‌های مهم
- `src/intake/` — موتور تحلیل نیاز (بزرگ‌ترین دامنهٔ کد)
- `src/lib/` — ۶۹ ماژول دامنه
- `prisma/schema.prisma` — ۶۳ مدل، ۱۷ بخش دامنه‌ای
- `src/middleware.ts` — canonical/legacy URL handling
- `docs/` — ۱۳۷ فایل، مرجع فنی تفصیلی اصلی (این Vault فقط لینک می‌دهد، کپی نمی‌کند)
