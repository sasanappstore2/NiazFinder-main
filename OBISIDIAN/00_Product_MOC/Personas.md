# شخصیت‌های کاربری

## ۱) مشتری / کارفرما (Need Poster)

- **هدف:** ثبت نیاز و پیدا کردن انجام‌دهنده مناسب
- **مسیرهای کلیدی:** `/` → `/post` → `/n/...` → `/v/...` → چت
- **دردها:** فرم طولانی، دسته‌بندی اشتباه، بی‌اعتمادی به کیفیت
- **بخش‌های مرتبط:** [[../10_Product_Areas/01_Home_Landing|01]] [[../10_Product_Areas/02_Need_Intake|02]] [[../10_Product_Areas/03_Need_Marketplace|03]] [[../10_Product_Areas/07_Communication_Chat|07]]

## ۲) کسب‌وکار / متخصص (Business)

- **هدف:** دیده شدن، دریافت لید، بستن قرارداد
- **مسیرهای کلیدی:** `/b/iran` → پروفایل → لیدها → چت → پیشنهاد
- **دردها:** لید کم‌کیفیت، پروفایل ضعیف، پاسخ دیر
- **بخش‌های مرتبط:** [[../10_Product_Areas/04_Business_Marketplace|04]] [[../10_Product_Areas/05_Business_Profile|05]] [[../10_Product_Areas/06_Matching_Leads|06]] [[../10_Product_Areas/09_Dashboard_Owner|09]]
