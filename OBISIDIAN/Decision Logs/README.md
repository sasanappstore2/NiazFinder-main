# Decision Logs

## هدف
تصمیم‌های عملیاتی/کوچک‌تر روزمره — برخلاف ADR که فقط برای تصمیم‌های **بزرگ معماری** است.

## تفاوت با ADR
| | Decision Log | ADR |
|---|---|---|
| مقیاس | تصمیم کوچک، محدود به یک جلسه/کار | تصمیم بزرگ معماری با پیامد درازمدت |
| فرمت | یک یا چند خط، تاریخ‌دار | Context/Decision/Alternatives/Consequences/Trade-offs |
| نمونه | «فی لید عادی ۱۰هزار، باکیفیت ۲۰هزار تومان تعیین شد» | «معماری کیف پول Pay-as-you-go انتخاب شد نه اشتراک صرف» |

## ورودی‌ها

### ۲۰۲۶-۰۷-۱۶ — رابطهٔ OBISIDIAN ↔ docs/
تصمیم: OBISIDIAN به `docs/` **لینک می‌دهد، کپی نمی‌کند** (نه بازنویسی کامل). دلیل: `docs/` (۱۳۷ فایل) فعلاً به‌روزتر و مرجع فنی اصلی است؛ کپی کامل باعث drift می‌شد.

### ۲۰۲۶-۰۷-۱۶ — قیمت‌گذاری دو سطحی لید
تصمیم: لید عادی ۱۰,۰۰۰ تومان، لید باکیفیت (شماره تاییدشده + بودجه + منطقه + urgency مشخص) ۲۰,۰۰۰ تومان — جایگزین فی تخت قبلی ۵,۰۰۰ تومانی. پیاده‌سازی: `src/lib/smart-matching/send-vip-lead.ts`.
