# Research

## هدف
یافته‌های تحقیقی/آزمایشی که مستقیماً معماری نیستند اما تصمیم‌های آینده را شکل می‌دهند.

## یافته‌های شناخته‌شده (از حافظهٔ جلسات قبلی)
- **Embedding مدل‌ها برای دستهٔ `/post`**: baseline ها امتحان شد؛ Gemini و e5 در این کاربرد نتیجهٔ خوبی ندادند، `bge-m3` انتخاب شد.
- **Hybrid RAG برای تشخیص شهر/استان**: طراحی مجموعه‌داده/embedding/retrieval برای grounding مکان.
- **Propose→Validate pipeline**: LLM پیشنهاد ۵ گزینهٔ برتر می‌دهد → داده اعتبارسنجی می‌کند → نتیجهٔ نهایی، برای دسته‌بندی و مکان.
