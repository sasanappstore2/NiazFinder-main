# VISION

NiazFinder is an **AI-first Need Intelligence Platform** — not an advertisement website and not a form-first product.

## North star

Understand human need (intent, hidden intent, category, location, entities, constraints, preferences, ambiguity, confidence) with minimal manual input. The user mainly verifies and corrects. The form is a structured projection of understanding.

## Product spine

```
free-text need → NeedDraft → publish → marketplace → match/leads → chat → proposal → trust
```

## Non-goals

- Classified-ads clone
- LLM-gated publish
- Presentation calling models directly
- Typesense as need authority
- Illegal data scraping
